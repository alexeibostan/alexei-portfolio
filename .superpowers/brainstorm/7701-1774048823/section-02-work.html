Project Layout — Featured + Grid

One project is always "featured" — expanded as a two-column case study with Problem → Craft → Impact on the right. The remaining projects sit below as compact cards. Clicking a compact card smoothly expands it into the featured position while the previous one collapses. The arrow icon hints at interactivity.

Interaction & Animation

  • Scroll entry: Section header and featured project slide up with fade-in. Compact cards stagger in from the bottom (50ms delay each).
  • Card swap: Clicking a compact card triggers a smooth expand/collapse animation — the clicked card grows into the featured slot, the previous featured card shrinks into the compact row. Content cross-fades.
  • Hover on compact cards: Subtle border glow + slight lift (translateY -2px). Arrow rotates to point right.
  • Tech pills: Each tech category has its own color — consistent with the palette used across the site (green for frontend, blue for backend, purple for mobile, gold for languages).
  • Mobile: No split layout — featured project stacks vertically (identity on top, case study below). Compact cards become full-width, stacked. Tap to expand replaces hover.

Content Note

The Problem → Craft → Impact structure means you'll want to rethink each project's description. Instead of generic summaries, each project needs a user problem it solved, the technical approach you chose, and the result. This ties directly into your brand — every project framed through the lens of user value. The descriptions above are placeholder approximations.
